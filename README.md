# 📋 Smart Student Attendance System

A simple Python terminal-based application designed to manage classroom attendance, register student names dynamically, and generate instant attendance reports.

## 🚀 Features
* **Dynamic Student Input:** Enter total student count and register names easily.
* **Real-time Attendance Tracking:** Fast `Y/N` status input for each student.
* **Detailed Reporting:** Displays total count, present/absent metrics, and lists.
